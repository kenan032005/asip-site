# 浏览器 QA

## 构建产物
- `build_site.py --no-embed` 退出码 0。
- `dist/` 输出 **378** 个 HTML 页面（9 类页面 + 13 国家 + 105 实体 + 203 关系 + 索引等）。

## 静态链接完整性
- 遍历全部本地 `href`，排除 `#` 与 `http(s)` 外链。
- 检查 **1832** 个链接，全部指向存在的本地文件。
- 被工具标记「missing」的 15 个均为内联 JS 模板字面量 `href="${url}"` / `href="country.html?country=${encodeURIComponent(...)}"` 等占位符，运行时由 JS 解析，**非真实断链**。

## 结论
无真实断裂的内部链接，构建产物结构完整、可静态浏览。
