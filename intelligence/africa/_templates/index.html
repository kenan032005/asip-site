04

重要程度与等级体系说明

三个独立概念：实体重要程度（L1/L2/L3）、国家风险等级（extreme/high/medium/low）、事实可信度（high/medium/low/disputed），不得混用。

本知识库以统一实体 ID 与统一数据模型管理全非洲实体、关系、国家、地区、来源和证据。多区域实体只存在一个 ID 与一个档案页，通过 region_ids / country_ids 与关系数据体现其跨境活动范围。

当前事实均记录数据检查日期（record_reviewed_at）、来源发布日期（source_published_at）与事实有效截至（claim_valid_as_of）；当前状态另行记录核验日期（current_status_verified_at）。无近期公开来源的内容标注为「趋旧/过时」并提示。证据记录区分「已核验 / 部分核验 / 待复核」，自动生成记录不默认为已核验。武装规模估计带时间、口径、来源与可信度并并列展示，不取平均；Wikipedia 仅作辅助导航。正式页面构建后兼容 GitHub Pages 静态路由。

公开预览声明
  • 本知识库为公开来源安全信息整理，供分析参考，不构成官方认定或风险评估结论。
  • L1/L2/L3 为平台内部重要程度（维护与展示优先级）。
  • 国家风险等级为平台分析标签，非政府或国际组织评级。
  • 当前状态受公开信息时效限制；页面显示事实有效截至日期，过时内容会明确标注。
  • 存在争议或来源不足的内容会明确标注，不会以确定性口吻呈现。
  • 区域划分用于安全分析，不等于唯一正式地理分类。
