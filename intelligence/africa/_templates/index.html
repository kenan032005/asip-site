重要程度与等级体系说明

三个独立概念：实体重要程度（L1/L2/L3）、国家风险等级（extreme/high/medium/low）、事实可信度（high/medium/low/disputed），不得混用。

本知识库以统一实体 ID 与统一数据模型管理全非洲实体、关系、国家、地区、来源和证据。多区域实体只存在一个 ID 与一个档案页，通过 region_ids / country_ids 与关系数据体现其跨境活动范围。

当前事实均记录 last_verified / as_of_date；武装规模估计带时间、口径、来源与可信度并并列展示，不取平均；Wikipedia 仅作辅助导航。正式页面构建后兼容 GitHub Pages 静态路由。
